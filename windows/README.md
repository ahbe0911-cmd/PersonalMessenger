# Personal Messenger for Windows

Windows 10 (build 19041 or later) / Windows 11 x64. Native WinForms shell with WebView2 Evergreen and a self-contained .NET 8 runtime. Existing hosted web application and session logic are unchanged. The WebView2 profile resides under LocalAppData; browser session-cookie lifetime remains controlled by the web service. Closing hides the window in the tray; use the tray menu to exit completely. File drop onto the attachment picker uses browser support. Microphone permission is user-controlled. Notifications reflect rendered incoming messages only, not guaranteed real-time push while hidden. Internet is needed to use the messenger and install WebView2 if missing. Installer is not code-signed; SmartScreen may warn. CI builds and hashes the installer; physical Windows installation and device testing remain required.

1.0.1: display WebView2 navigation status and initialization HRESULT; explicit retry, browser and health links. TLS validation and trusted-origin restriction retained. No server or Android changes.
